# M4: public site

## Scope

The public website (`src/app/(site)`), the shared public blocks and components (`src/components/public`, `src/components/landing`), the public header and footer, and the sign-in page frame. Page metadata (titles, descriptions, Open Graph) is unchanged.

## What changed

- **Homepage**
  - New hero: a plain headline, beacon "Start advertising" and an outline "Become a driver partner".
  - The **route line**: an illustrated diagram of a campaign going from advertiser, to review, to vehicle screen (marked "Live"), to driver partner. It draws itself once on load, the homepage's only orchestrated motion, and is static under reduced motion.
  - Removed: the animated city scene, the stats strip ("Two-sided", "Trackable"…), gradient cards, the all-caps eyebrow and the coloured headline words.
- **One purpose per page**
  - Home: what AdVibe is and the two ways to use it.
  - For advertisers: how a campaign runs and what you control.
  - For drivers: what partnering means, the vehicles, the steps and the requirements.
  - Ad formats: compare placements and choose one.
  - Pricing: how cost is built up, with an example calculator.
  - Locations: area-based planning with clearly labelled samples.
  - About: why AdVibe exists and how it works. The redrawn "AdVibe" wordmark art was removed, because it broke the logo rule.
  - Contact: write to the team.
  - Help centre: search answers.
  - Repeated blocks (the coverage map on three pages, format grids everywhere) were removed.
- **Map fix (finding H6):** the jagged black shapes came from an SVG path with strokes but no `fill`, which browsers fill black. It now has `fill="none"`, and the map is restyled as a labelled schematic.
- **Format illustrations:** the sunset-gradient "YOUR BRAND HERE" scenes are replaced by quiet line drawings, each marked "Illustration" on the artwork.
- **Components restyled on design tokens**, with their logic unchanged: format catalogue, pricing calculator (same formula and example rates), location planner (same sample data), driver vehicle tabs, contact form (same validation and `mailto:` behaviour), help search, FAQ list. The "Compare all formats" tables on the formats and pricing pages were removed, because each comparison now sits on the cards and in the calculator.
- **Header and footer**
  - Sentence-case labels; "Login" is now "Sign in".
  - Removed "Admin Portal (Demo)", the "UI Components" link (done in M2), "Frontend demonstration." and the middle-dot tagline (finding MD7).
  - Mobile menu links no longer each end with an arrow.
- **Sign-in frame:** plain night panel, no animated scene or coloured headline words.
- **FAQ answers** updated where they described an older state of the product. Accounts and support tickets work now, and there is no "six-step workflow".
- **Logo derivative:** `public/brand/advibe-logo-800.png` is a resized copy of the same artwork (800 × 267, 134 KB). `BrandLogo` now uses it, so image resizing starts from a smaller file. Correction to audit finding L2: browsers never downloaded the 633 KB original; `next/image` already served about 17 KB WebP at header size.
