# BlinkMyAd identity

Owner-approved direction, 8 November 2026: replace the public AdVibe identity throughout the website with BlinkMyAd. The owner delegated the logo and art direction, requested blue/white/charcoal with sparse purple, mostly light pages, compact controls, cinematic public motion and restrained portals.

- Public name: **BlinkMyAd**
- Company name supplied by the owner: **Blink My Ad Pvt Ltd**
- Working brand line: **Make your next move visible.**
- Initial pilot city: **Prayagraj**
- Public email, telephone and WhatsApp: **unpublished** until the owner supplies approved details. Do not invent addresses or revive legacy mailto links.

The new logo is `public/brand/blinkmyad-logo.png`: a cobalt B symbol with a forward cut and a charcoal wordmark, generated specifically for this brief. It is a trimmed 1000px web derivative. `public/icon.png` uses the same symbol. `BrandLogo` owns all UI use; its inverse treatment is white on charcoal. Do not mix the former megaphone/BMA logos with this identity. Older masters remain in Git history and retained asset directories for provenance only.

Brand configuration lives in `src/config/brand.ts`. Keep internal `ADVIBE_*` variables, database names, API paths, browser storage keys and session contracts unchanged. Public branding does not imply that company registration, policies, hardware installation or service availability have been independently verified.
